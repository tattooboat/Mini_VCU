## 三、系统结构

``` text
触摸屏 / LVGL 控制页
        |
        | START / STOP / 目标值设置
        v
本地电机控制应用层
        |
        | 控制目标与使能状态
        v
FreeRTOS 电机控制任务
        |
        | PID 运算 / 安全检查
        v
PWM 电机驱动
        |
        v
直流电机
```

  模块                 主要职责
  -------------------- --------------------------------------------------
  LCD/LVGL UI          页面显示、触摸交互、运行状态展示
  本地电机控制应用层   管理启动/停止请求和目标值
  FreeRTOS 控制任务    周期性读取控制请求并执行控制逻辑
  PID 模块             根据目标值进行控制计算
  电机驱动模块         输出 PWM，控制电机运行
  故障管理             检查异常状态，触发安全停机和恢复流程
  CAN 通信模块         保留双节点通信能力，不作为本地触摸控制的必经链路

## 四、关键设计说明

### 1. 本地直控

采用 F407 本地直控。触摸屏直接更新本地控制请求，由 F407
控制任务执行，不再依赖 CAN 报文才能控制本机电机。应避免 CAN
控制与本地触摸控制同时争夺电机控制权。

### 2. PWM 控制入口统一

LVGL 回调不直接调用底层 PWM
输出函数。启动、停止和目标值修改通过应用层接口传递给控制任务，PWM
输出由控制任务统一管理。

### 3. 编码器反馈与真实转速显示

本机采用**带编码器的直流减速电机**，编码器接 TIM8（配置为编码器模式）：
- 由 `Int_Encoder_GetOutputRPM` 按脉冲数、解倍数和减速比换算得到**真实实测转速**。
- 主页 `MOTOR SPEED` 显示的是编码器实测实际转速，`TGT` 显示目标转速，两者分开展示，实现速度闭环的基础。
- 控制任务读取编码器并发布 `g_ui_actual_rpm`，供 UI 显示；修改变量化前应核对减速比与脉冲数参数，保证换算准确。

## 九、追加：界面优化与急停整合改动记录

本次在 Day 4 基础上对 UI 与安全逻辑做了如下调整，并修复了实测中发现的问题。

### 9.1 新添加 / 修改内容

| 项目 | 说明 |
| ---- | ---- |
| 控制页按钮重排 | 由拥挤多行小按钮改为**三行两列大按钮**（实际转速/启停/调速/急停复位），按钮高度提升到 34px，消除重叠、触摸命中区更大 |
| 全页面禁用滚动 | 主页、控制页及其所有卡片统一 `LV_SCROLLBAR_MODE_OFF`，页面固定不滑动，避免触摸屏误滑或触发翻页 |
| 急停(E-STOP)最高优先级锁存 | 新增 `App_MotorControl_EMStop/IsEMLatched/ReleaseEMStop`，E-STOP 后立即停机并 **锁存**，忽略一切外部/本地目标，直到显式 RESET；新增 `FAULT_EMERGENCY_STOP` 与 `MOTOR_FAULT_ESTOP` 故障/反馈码 |
| RESET 与回归 CAN 合并 | 原「RESET」与「CAN MODE」合成一个 `RESET`：急停锁存时复位急停，否则释放停机锁存交还 CAN，减少一个按键、步骤更少 |
| 主页显示真实数据 | 移除演示值 `120 km/h / DEMO VALUE`，改为主页显示真实实际转速(`MOTOR SPEED`)、目标转速(`TGT`)、PWM 占空比、运行状态(`RUNNING/STOPPED/E-STOP`)与反馈 `TX` |
| 状态联动真实化 | 电机运行状态、PWM、目标值均取自控制任务发布的 `g_ui_actual_rpm/g_ui_target_rpm/g_ui_pwm`，本地/CAN 两种模式都显示真实数据，并明确区分"实际转速"与"目标转速" |
| 浮点显示格式修复 | 主页速度由 `%.0f`（精度浮点）改为 `%d` 取整显示，规避设备端内置 printf 对浮点精度渲染乱码的问题 |

### 9.2 实测中遇到的问题与解决（用户反馈汇总）

| 问题 | 现象 | 处理 |
| ---- | ---- | ---- |
| 控制页按钮重叠 | 原布局按钮尺寸偏小、第二行与第一行底部重合，视觉拥挤、难按准 | 重排为三行两列大按钮，行间隔 4px，等宽对齐，无重叠 |
| 触摸不灵敏、易滑动 | 触摸命中区小、页面疑似可滑动 | 放大按钮（34px 高、140px 宽），并对整页与所有卡片禁用滚动 |
| 主页速度不是真实数据 | 仍显示 `120 km/h / DEMO VALUE` 等演示值，标题 `VEHICLE SPEED` 语义误导 | 改为 `MOTOR SPEED` + 真实实际转速、`TGT` 目标转速、`PWM` 与真实运行状态，删除全部演示文案 |
| 主页速度框显示乱码（`frmp`） | `%.0f` 精度浮点在设备内置 printf 下未能正常输出数字，界面出现异常字符 | 将实际/目标转速改为 `%d` 整数取整显示，乱码消失、显示干净整数 |
| 操作步骤偏多 | 启停、调速、急停、回归 CAN 分散在多个小按钮，逻辑零散 | 归并 `RESET`/`CAN MODE`，按"启停 → 调速 → 急停/复位"三行分组，步骤更直观 |

### 9.3 相关说明（编码器反馈）

本机为**带编码器的直流减速电机**。主页速度框由控制任务发布的 `g_ui_actual_rpm`（`Int_Encoder_GetOutputRPM` 读取 TIM8 编码器换算）驱动，显示的是**编码器实测真实转速**；`TGT` 显示目标转速。后续只需核对编码器脉冲数/解倍数/减速比参数，即可保证换算准确、用于闭环 PID 验证。
