# Mini VCU + ILI9341 LCD 开发记录

## Day 1：LCD 基础驱动与 FreeRTOS 显示验证

### 一、当天目标

在现有 STM32F407VGT6 Mini VCU 工程中接入 2.4 寸 ILI9341 SPI TFT
屏幕，验证基础显示驱动，并确认屏幕能够在 FreeRTOS 环境下持续刷新。

### 二、硬件与开发环境

-   主控：STM32F407VGT6
-   显示屏：2.4 寸 SPI TFT，ILI9341，分辨率按当前驱动设置为 320 × 240
-   开发环境：STM32CubeMX、Keil、HAL 库、ST-Link
-   RTOS：FreeRTOS（通过 CMSIS-RTOS 接口创建任务）
-   背光：实测将屏幕 `LED` 引脚接至 3.3V 后，背光能够点亮

> 注意：模块的背光电路细节仍需以具体板卡资料为准。后续长期使用前，应确认板载限流/驱动设计；不要在未确认电路的情况下直接改接
> 5V。

### 三、LCD 接线记录

当前软件 SPI 接线如下：

  屏幕引脚       STM32F407VGT6 引脚   说明
  -------------- -------------------- ----------------------------
  VCC            5V                   模块供电，已测得约 5V
  GND            GND                  与开发板共地
  SCK            PC0                  软件 SPI 时钟
  SDI（MOSI）    PC1                  主控向屏幕发送数据
  CS             PC3                  片选
  D/C            PC4                  命令/数据选择
  RESET          PC5                  屏幕复位
  LED            3.3V                 已实测背光点亮
  SDO（MISO）    暂不连接             当前显示测试未使用读取功能
  触摸相关引脚   暂不连接             后续再验证触摸控制器

接线调整前先断电。测量电阻时必须断电；测量电压时使用直流电压档，并避免表笔碰到相邻引脚造成短路。

### 四、工程文件与当前驱动

已创建并加入工程：

-   `lcd_ili9341.h`
-   `lcd_ili9341.c`

当前头文件定义了：

-   `LCD_WIDTH`：320
-   `LCD_HEIGHT`：240
-   `LCD_BLACK`、`LCD_RED`、`LCD_GREEN`、`LCD_BLUE`、`LCD_WHITE`
-   `LCD_Init()`
-   `LCD_FillColor(uint16_t color)`

当前驱动采用 GPIO 模拟 SPI，使用
PC0、PC1、PC3、PC4、PC5。初始化过程包含硬件复位、软件复位、退出睡眠、RGB565
像素格式设置、显示方向设置以及打开显示。`LCD_FillColor()`
会设置整屏窗口并写入 RGB565 颜色数据。

当前实现是用于验证的最小实验驱动，尚未实现文字、画点、图形绘制和触摸读取功能。后续扩展时应在现有已验证版本上逐步增加功能。

### 六、遇到的问题与解决办法

#### 1. 屏幕完全黑屏

**现象：** VCC 已供电，但屏幕没有可见亮光。

**排查过程：** 起初 `LED` 引脚未连接。之后实测将 `LED` 接到
3.3V，背光能够点亮。

**结论：** 此模块在当前接法下需要正确处理背光引脚。背光点亮不等于 LCD
数据通信必然正常，因此还需通过显示测试验证。

#### 2. 颜色代码放在 `main()` 的 `while (1)` 中无法循环

**原因：** 工程启用了 FreeRTOS。`osKernelStart()`
启动调度器后，正常情况下程序不会继续执行 `main()` 后面的无限循环。

**解决办法：** 将四色循环放到单独的 FreeRTOS 任务中，使用 `osDelay()`
在颜色之间延时。LCD 初始化只执行一次，任务负责反复调用
`LCD_FillColor()`。

### 七、当前代码结构建议

``` text
工程
├── Core/
│   ├── Inc/
│   └── Src/
├── USER/                 （如果项目采用 USER 文件夹）
│   ├── lcd_ili9341.h
│   └── lcd_ili9341.c
└── ...
```

`lcd_ili9341.c` 必须加入 Keil 的源文件编译组；头文件所在目录需要加入
Include
Paths。头文件和源文件可以放在项目约定的位置，但不要保留多份同名驱动文件，以免后续修改错文件。
